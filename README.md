# 7 вершин

**Своя вершина — каждый день**

Кабинеты группы киокушинкай (ИКО Мацуи): дневник ОФП, уроки техники, пути мастеров.

Прод: **https://7vershin.vorobjev.pro**

Логотип: `public/logo.svg`, `public/logo.png`, favicon — семь вершин и слоган.

Семья смотрит кабинет своего ребёнка. Сравнения учеников между собой нет.

## Стек

Vue 3 + Vite + Vue Router + Chart.js

## Личные данные

ФИО, даты рождения, вес, PIN учеников **не хранятся в git**.

```bash
cp src/data/athletes/roster.example.js src/data/athletes/roster.local.js
# заполните roster.local.js локально
```

`roster.local.js` в `.gitignore`.

## Команды

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # dist/ → хостинг
```

## Что внутри

- Сезон ОФП с циклами и домашним блоком (вт/чт — додзё)
- Уроки: ОФП, подводящие, гири/гантели для старших, скакалка, этикет, «Пути»
- Рекомендательный характер: разминка и присмотр взрослых (см. пометки в приложении)

## Пока не входит

Бот VK/Max, серверная БД, запись семьёй в дневник из приложения.
