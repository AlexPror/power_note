# Образец сообщения в чат родителям (без ПДн)

Скопируйте и подставьте имя ребёнка / цифры.

---

Здравствуйте!

Просим коротко отмечать домашние тренировки в чат группы (или лично тренеру). Достаточно одного сообщения после занятия.

**Формат:**

```
Дата: 18.09
Кто: (имя ребёнка)
Где: дома / додзё

Сделали:
• Отжимания — 3×8
• Пресс — 3×15
• Планка — 3×30 с
• Вис / подтягивания — …
• Скакалка — 2×40
• Приседания — 3×12
(что не делали — просто не пишите)

Самочувствие: норма / устал(а) / пропуск (причина)
Вопросы тренеру: …
```

**Пример заполнения:**

```
Дата: 18.09
Кто: … 
Где: дома

Сделали:
• Отжимания — 3×10 (с колен 2 подхода)
• Пресс — 3×12
• Планка — 25 с, 20 с, 20 с
• Скакалка — 50 прыжков
• Приседания — 3×10

Самочувствие: норма
```

Напоминание: разминка перед упражнением; дома — под присмотром взрослого. План рекомендательный; объём можно чуть снизить, технику не ломать.

Спасибо!
